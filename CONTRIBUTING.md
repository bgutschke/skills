# Contributing

This repo does not currently accept external pull requests. It's solo-maintained, and
`docs/agents/issue-tracker.md`'s "PRs as a request surface" flag stays `no` — PRs opened
against this repo won't be triaged or merged as contributions.

Issues are welcome: bug reports, a skill behaving unexpectedly, or a proposal for a new
skill. File one with `gh issue create` or the GitHub UI.

The repo is MIT-licensed (see [`LICENSE`](./LICENSE)) — forking it to adapt for your own
use is fine without asking.

## If PRs open up later

Any contributed skill would need to meet the bar in
[`CODING_STANDARDS.md`](./CODING_STANDARDS.md): required `SKILL.md` structure, style
rules, and the pre-merge checklist. That document is the standing reference regardless of
whether this file's PR policy changes.
